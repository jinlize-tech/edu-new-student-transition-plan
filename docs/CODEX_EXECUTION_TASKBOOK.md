- 版本基线：`EDUCATION_BASELINE_V1.0.0`
- 产品版本：`1.0.0`
- 许可证：Apache-2.0

## 2. 用户、痛点与目标

- 用户：班主任、教务、课程顾问、家长沟通人员、新教师
- 痛点：新生报名后到稳定上课之间缺少结构化适应流程，常见问题是路线不熟、规则不清、家长焦虑和首月流失。
- 目标：根据学生年龄、班型和家庭情况设计入学前、第1课、第1周和首月的适应任务与检查点。

## 3. 输入契约

| 键 | 名称 | 类型 | 必填 |
|---|---|---|---|
| `student_age` | 学生年龄或年级 | string | 是 |
| `program_and_class` | 课程与班型 | string | 是 |
| `start_date` | 开课日期 | string | 是 |
| `logistics` | 到校与设备信息 | string | 是 |
| `learning_history` | 学习经历摘要 | string | 否 |
| `parent_concerns` | 家长关注点 | array | 否 |
| `staff_assignments` | 教师与教务安排 | array | 是 |
| `campus_rules` | 校区规则 | array | 是 |

## 4. 工作流

1. 确认目标与边界
2. 生成入学前资料
3. 设计第一课适应任务
4. 分配家长/教师动作
5. 设置观察与回访节点
6. 输出首月复盘表

## 5. 阶段状态

| 阶段 | 动作 | 退出成果 |
|---|---|---|
| S1_SCOPE_CONFIRMATION | 确认目标、校区/岗位/课程范围、期限、交付格式和可用资料。 | 任务确认单与最多3个关键缺口 |
| S2_EVIDENCE_INVENTORY | 盘点学生年龄段、课程与班型、开课日期、交通/设备、学习经历、家长关注点、教师安排、机构规则，标记来源、版本、敏感字段与冲突。 | 证据清单、缺口表和冲突表 |
| S3_PROFESSIONAL_DIAGNOSIS | 围绕根据学生年龄、班型和家庭情况设计入学前、第1课、第1周和首月的适应任务与检查点。进行专业诊断，形成问题树和优先级。 | 问题树、风险和优先级 |
| S4_SOLUTION_DESIGN | 按确认目标与边界 → 生成入学前资料 → 设计第一课适应任务 → 分配家长/教师动作 → 设置观察与回访节点 → 输出首月复盘表设计首选方案和受限备选方案。 | 方案、责任人、完成标准 |
| S5_HUMAN_CONFIRMATION | 由业务负责人复核输入事实、关键假设和最终成果适用范围。 | 确认记录、未决项和升级项 |
| S6_FINAL_DELIVERY | 生成完整交付成果，执行结构、证据、安全、品牌和独立安装检查。 | 最终成果、范围限制和复盘指标 |

## 6. 核心成果

- `新生适应计划`
- `第一课流程`
- `风险升级条件`

## 7. 差异化与排重

- 与现有产品：现有学员名册管理信息，家校沟通 Agent 管持续沟通；本产品是新生首月成功路径的专项设计。
- 排重检查：有限重叠；共享学生和家长信息，但输出首月适应流程，不管理长期沟通或名册。
- 独立理由：只安装本产品即可完成新学员入学适应设计。

## 8. 安全与人工门禁

- 复核角色：业务负责人
- 复核范围：输入事实、关键假设和最终成果适用范围
- 不调用外部收费API。
- 不自动修改外部系统、执行退款、审批合同、处分员工或联系外部人员。
- 高风险产品完成状态必须确认人工复核。
