# 新生入学适应计划专业工作手册

## 操作原则

1. 先确认任务范围和数据口径，再开展专业分析。
2. 输入事实、模型推断和未决假设分开记录。
3. 每条结论都应可追溯到用户输入、已核验来源或明确假设。
4. 高风险结论必须进入人工确认，不以建议代替正式决定。

- `新生适应计划`：不能是空壳；每条至少包含结论、依据、风险/限制和下一步。

## 异常处理

- 输入缺失：`needs_input`，列出最多3个关键问题和当前受限草案。
- 资料冲突：`needs_confirmation`，并列版本和影响。
- 工具不可用：`failed`或`completed_with_limits`，说明失败范围。
- 敏感信息：先脱敏；必要时`needs_confirmation`。
- 越权请求：拒绝正式审批、系统修改或外部触达，给出合规替代。
