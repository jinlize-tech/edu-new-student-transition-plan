# 新生入学适应计划领域指南

## 业务问题

新生报名后到稳定上课之间缺少结构化适应流程，常见问题是路线不熟、规则不清、家长焦虑和首月流失。

## 产品解决方案

根据学生年龄、班型和家庭情况设计入学前、第1课、第1周和首月的适应任务与检查点。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `student_age` | 学生年龄或年级 | 是 | 用于设计适龄适应任务 |
| `program_and_class` | 课程与班型 | 是 | 首次课、上课频次和教师安排 |
| `start_date` | 开课日期 | 是 | ISO 日期或明确日期口径 |
| `logistics` | 到校与设备信息 | 是 | 交通、接送、设备和场地 |
| `learning_history` | 学习经历摘要 | 否 | 不包含不必要的医疗或家庭隐私 |
| `parent_concerns` | 家长关注点 | 否 | 用户主动提供的关注事项 |
| `staff_assignments` | 教师与教务安排 | 是 | 角色和责任 |
| `campus_rules` | 校区规则 | 是 | 新生需要理解的规则 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

不得收集无关家庭信息；适应问题严重时需专业教师/心理或医疗人员处理；不替机构承诺效果。
